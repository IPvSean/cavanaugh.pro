BRKATO-2106

Ansible Network Automation, GitOps for NetOps

Cisco Live Las Vegas, Nevada June 2023 While at Red Hat

A new paradigm shift has created a more opinionated and simpler model: GitOps. This talk covers a simple network as code approach where your Source of Truth is simply a Git Repository and every pull request starts your automation workflow. Co-presented with Adrian Iliesiu (Cisco Distinguished Speaker).

Co-presenter: Adrian Iliesiu, Principal Engineer, Cisco
