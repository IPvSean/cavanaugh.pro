The upcoming Ansible 2.5 open source project release has some really exciting improvements. In typical Ansible fashion, development of networking enhancements is done in the open with the help of the community.

A few highlighted features include:

- **New Connection Types:** network_cli and NETCONF
- **Ansible Fact Improvements**
- **Improved Logging**
- **Continued Enablement for Declarative Intent**
- **Persistent SSH Connection Improvements**
- **Additional Platforms and Modules**
